저장소 보기 동작 방식

⚡

제로 빌드

번들러도 프레임워크도 없습니다. index.html 을 수정하고 push 하면 1~2분 안에 반영됩니다.

📱

반응형

CSS Grid 와 상대 단위로 구성해 모바일부터 와이드 모니터까지 가로 스크롤 없이 자연스럽게 배치됩니다.

🌙

다크 모드

OS 테마 설정을 prefers-color-scheme 로 감지해 라이트/다크 색상을 자동으로 전환합니다.

동작 방식

  1. 로컬에서 수정 index.html / style.css 를 편집합니다.
  2. 커밋 & 푸시 git add -A && git commit -m "update" && git push
  3. 자동 배포 GitHub 이 main 브랜치 루트를 그대로 서빙합니다.
로컬 미리보기

프로젝트 폴더에서 아래 명령을 실행한 뒤 http://localhost:8000 에 접속하세요.

python -m http.server 8000
